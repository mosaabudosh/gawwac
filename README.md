# GawwaC – Transportation Company Website

## Project Overview

GawwaC is a static, responsive company website designed to present a transportation business, its services, and its activities.

The website provides visitors with information about the company, its vision and mission, transportation services, customer and driver information, news, events, and contact channels.

This project focuses on the frontend presentation and user interface.

## Features

- **Company Overview:** Introduces the company and its business.
- **Vision & Mission:** Presents the company's goals and direction.
- **Transportation Services:** Displays transportation-related content and services.
- **Customer & Driver Sections:** Provides dedicated information for customers and drivers.
- **News & Events:** Showcases company news and activities.
- **Join Us Section:** Provides information for visitors interested in joining the company.
- **Mobile Application Links:** Includes Google Play and Apple App Store links.
- **Contact Information:** Displays company contact and social media information.
- **Responsive Layout:** Uses responsive styling to support different screen sizes.

## Getting Started

The project is a static website and does not require a backend server or database.

### Run Locally

1. Download or clone the project.
2. Open the `End_GawwaC` directory.
3. Open `index.html` in your web browser.

Alternatively, you can run it using a local development server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
